Java 21 LTS | 2024

Telepítés

A Sudoku alkalmazáshoz Java 21 vagy újabb szükséges.

Java ellenőrzése

Nyiss egy terminált és írj be:

java -version

Az output valahogy így kell kinézzen:

openjdk version "21.0.x"

Ha nincs Java telepítve, telepítsd le az OpenJDK 21-et:

  • Windows/Linux: Látogass el az jdk.java.net oldalra
  • macOS (Homebrew): brew install openjdk@21

Az alkalmazás futtatása

java -jar sudoku.jar

Vagy ha van Maven:

mvn exec:java -Dexec.mainClass="hu.bme.sudoku.gui.GameWindow"

A játék indítása

Nyisd meg az alkalmazást. Az első képernyőn választhatsz a nehézségi szintek közül:

  • Kezdő - 50 kitöltött cella, könnyen megoldható
  • Haladó - 35 kitöltött cella, középere szintű
  • Profi - 25 kitöltött cella, nagyon nehéz

Válaszd ki az általad kívánt szintet, és a játék kezdődik.

Alapvető szabályok

A Sudoku egy logikai rejtvény, amelynek egyszerű szabályai vannak:

  • A tábla 9×9 cellákból áll, amely 9 darab 3×3-as blokkra van osztva.
  • Minden sorban, oszlopban és 3×3-as blokkban az 1-9 számok pontosan egyszer jelennek meg.
  • Az üresen hagyott cellákat fel kell tölteni az 1-9 számok közül.
  • Csak azokat a számokat használhatsz, amelyek nem jelennek meg az ugyanabban a sorban, oszlopban vagy blokkban.

Játékmenet

Cellák kitöltése

  1. Kattints az üresen hagyott cellára.
  2. Írj be egy számot az 1-9 közül.
  3. Az alkalmazás automatikusan ellenőrzi, hogy a szám érvényes-e.
  4. Ha érvényes, a szám marad. Ha nem, hibajelzést kapsz.

Cellák törlése

  • Kattints a cellára és nyomj meg egy üres billenty (Delete vagy Backspace).
  • A szám törlődik a cellából.

Jelölt szám megjelenítése

A kiválasztott cella kékkel van kiemelve, így könnyedén nyomon követheted, hol dolgozol.

  • Szürke cella = fix szám (nem szerkeszthető)
  • Piros cella = hiba található itt
  • Zöld cella = helyes kitöltés
  • Kék cella = jelenleg kiválasztott

Menü funkciók

  • Új játék - Új rejtvény generálása az aktuális nehézségi szinten.
  • Ellenőrzés - Megvizsgálja a táblát. Ha van hiba, piros háttérrel jelzi. Ha kész és helyes, zöld háttérrel jelzi.
  • Megoldás mutatása - Kitölti az összes cellát a helyes válaszokkal.
  • Mentés - Elmenti az aktuális játékállapotot egy fájlba.
  • Betöltés - Betölt egy korábban mentett játékot.
  • Kilépés - Bezárja az alkalmazást.

Tippek és trükkök

Stratégia

  1. Szám-nyomkövetés: Nézd meg, hogy melyik sorokba, oszlopokba és blokkokba hiányzik az 1-es, 2-es stb.
  2. Csak lehetséges számok: Egy cellába csak olyan szám írható, amely nem jelenik meg az ugyanabban a sorban, oszlopban vagy 3×3-as blokkban.
  3. Egyedüli jelölt: Ha egy cellában csak egy lehetséges szám létezik, az az első kitöltendő cella.
  4. Láncos következtetés: Több logikai lépés összekapcsolása.

Tudnivalók

  • A rögzített cellák (szürke) nem módosíthatók
  • Az Ellenőrzés gomb csak azt jelzi, hogy van-e hiba, de nem oldja meg a feladványt
  • Az Új játék bármikor elkezdhet új rejtvényt
  • Az Mentés/Betöltés funkció lehetővé teszi több játékot párhuzamosan játszani
